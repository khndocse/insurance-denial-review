# 保险拒赔案件审核评估 Skill

面向办理保险拒赔争议的律师。拿到保单、拒赔通知和证据后，先定位影响给付的争议，再对照法院支持与不支持给付的理由，梳理需要补证的事项。

## 本机版的办案能力

- **按争点找正反类案。** 收录并逐案提炼国内五类险种保险拒赔争议的裁判文书，以 2024—2026 年文书为主。覆盖医疗险、重疾险、学平险、团体意外险和雇主责任险。可按险种、地区、法院和关键词筛选，结合保单条款和证据差异，回到原判比较支持给付与驳回请求的理由。
- **核对三类伤残评定标准。** 整理人身损害伤残评定、工伤劳动能力鉴定、人身保险伤残评定所用标准，协助律师核对适用版本、合同引用、鉴定意见及医学材料，列出下一步核验和补证事项。
- **对照重疾、轻症定义。** 整理新旧重疾定义规范和已收录产品的重疾、轻症条款，按实际保单核对疾病定义、诊断条件、手术要求和功能障碍门槛，定位可能影响给付的医学证据。

## 本仓库提供的社区版

社区版开放五类险种核查表、九档初评方法、报告模板和虚构演练，可在 Codex 等支持 Agent Skills 的客户端使用。做类案、鉴定标准或疾病定义对照时，使用者需提供相关材料或接入有权访问的来源。公开包以 Markdown 工作流程和参考文件交付，实际案件判断供律师复核。

## 安装到 Codex

在装有 Node.js 的环境执行下列命令，安装后重新打开 Codex 对话。

```sh
npx skills add khndocse/insurance-denial-review --skill insurance-denial-review --agent codex
```

也可以下载仓库，按客户端支持的方式放入技能目录。Codex 的项目级路径示例为 `.agents/skills/insurance-denial-review/`，保留 `SKILL.md`、`references/` 和 `examples/` 的相对位置。

## 试用

先用仓库中的[虚构演练](examples/fictional-review.md)熟悉结果，或提供已脱敏的保单及条款、拒赔通知和证据材料。

> 用 $insurance-denial-review 帮我审核这起医疗险拒赔。请逐条对应拒赔理由和保单条款，标出证据页码，给出初评、两种可能的金额和优先补证清单。

资料很少时，也可以先要求只盘点材料和梳理拒赔争点。初评供人工复核，金额随条款、付款归属及证据变化而重算。社区版使用虚构演练材料，实际案件由使用者自行提供所需资料。
