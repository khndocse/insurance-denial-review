# 保险拒赔审核参考

## 按实际责任核查

| 险种 | 优先核对 | 分开处理 |
| --- | --- | --- |
| 医疗险 | 保单年度、就医机构、费用是否符合责任、医保和其他补偿、免赔额剩余额及赔付比例 | 费用补偿、住院津贴、续保争议分别判断 |
| 重疾险 | 疾病定义、诊断材料、发病和确诊时间、等待期、条款要求的严重程度或治疗条件 | 重疾、中症、轻症、额外给付和保费豁免各核触发条件 |
| 学平险 | 被保险学生身份、参保时段、保单及批单列明的实际保障、事故或疾病证据 | 身故、伤残、意外医疗及附加医疗或津贴按实际投保项目拆开 |
| 团体意外险 | 投保单位与被保险人关系、名单或约定的纳入机制、事故时间与原因、约定职业及伤残标准 | 身故、伤残、医疗及附加责任分别审查，核对伤残标准和适用比例 |
| 雇主责任险 | 雇主和雇员身份、雇佣或用工关系、承保期间、事故与工作关系、雇主依法承担的赔偿及条款覆盖 | 工伤待遇、雇主向雇员承担的责任、保险人给付分别建账，核对请求主体、已付款和约定分项限额 |

险种名称取自实际合同和责任。材料只有销售名称时，注明暂用分类及待取得的正式保单。保单版本、保险期间或具体给付责任可识别时，再用下表结合本险种因素评估。

## 九档初评

评价对象为当前材料下的一项具体责任。决定性争点指可能改变主要给付是否成立或给付类别的争点。用定性证据分档，另记材料完备度和法律检索覆盖。

| 档位 | 判断依据 |
| --- | --- |
| A+ | 主要给付证据链完整，并有直接证据排除主要抗辩，或有可核实的保险人明确认可。 |
| A | 主要给付证据链完整，现有材料中无实质性的决定性抗辩。 |
| A- | 主要给付依据完整，剩余争议集中于计算、费用范围或附随请求。 |
| B+ | 有强证据支持主要给付，但仍有一个可能改变结果的决定性争点。 |
| B | 承保事件有基础，决定性争点双方均有材料或解释支撑，当前难以判断。 |
| B- | 现有证据在决定性争点上明显不利，但仍有具体材料或待核事实支持一条可说明的主张。 |
| C+ | 已有证据支持足以阻却该项给付的障碍，仍有狭窄且有依据的反驳路径。可另评替代责任。 |
| C | 决定性障碍有证据支持，未见有实质依据的反驳路径。 |
| C- | 多个独立决定性障碍已获证明，或同一请求已全额履行、已终局处理且范围已核实。 |

不知道条款是否存在、没拿到某个附件或尚未找到类案时，记录未知及影响。有核心证据缺失、无法识别责任或事件时暂不定档。主张成立、金额计算、是否承接案件各自说明。写明新证据在什么条件下会改变初评。

## 金额核算

- 先确认给付类型和适用条款。费用补偿核对可纳入费用、医保或其他给付、免赔额、比例、各级限额和已付保险金。按具体合同确认扣减口径与顺序。
- 定额给付从合同约定保险金额出发，按该责任实际适用的比例或档次计算。费用补偿的扣减方法只用于约定适用的责任。
- 雇主责任险逐项对照可保责任、实际款项、免赔与限额，防止将同一支出重复计入。金额证明、责任成立、请求主体分别核对。
- 以表格列出每个变量、来源、该项是否已扣除。金额有争议时逐种情景给出公式、成立条件和充分性。附随请求另列，评级保留为风险分档。
